03 / An evaluation, explained

The answer needs
to fit the question.

A sample response comparison. The source and prompt are included so you can check the decision.

Source

"The library closes at 6 p.m. on weekdays. It is closed on Sundays."

Task

Summarize the library's closing schedule in one sentence. Use only the source information.

Response APreferred for this task
The library closes at 6 p.m. on weekdays and is closed on Sundays.

One sentence. Both source facts. No added opening time.

Response BFor comparison
The library is open from 9 a.m. to 6 p.m. on weekdays. It is closed on Sundays.

Two sentences. Adds an opening time the source does not provide.

Response A meets the format

The task asks for one sentence. Response A uses one sentence; Response B uses two.

04 / How I work

From the source
to the decision.

The task guide sets the standard. My review follows the evidence.

  1. 01

    Read the task

    Identify the request, constraints, reference material, and rules for uncertain cases.

  2. 02

    Check the output

    Compare the answer or label with the source and the relevant rubric criteria.

  3. 03

    Record the reason

    Point to the evidence. Explain the correction or preference and note what remains unclear.

  4. 04

    Review once more

    Check consistency, required fields, and any case that needs clarification.
